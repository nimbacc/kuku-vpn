# Kuku VPN 🐔

### کلاینت اندروید // هستهٔ sing-box
**«متصل» فقط وقتی تأیید می‌شود که یک درخواست واقعی از تونل عبور کند و پاسخ برگردد.**

Kuku VPN یک کلاینت VPN متن‌باز برای اندروید است که روی هستهٔ [sing-box](https://github.com/SagerNet/sing-box) سوار است — با فلسفهٔ طراحی «تأیید اتصال واقعی»، زنجیرهٔ جایگزینی خودکار و رابط فارسی/انگلیسی.

---

## 🏆 امکانات

| امکان | توضیح |
|---|---|
| 🟢 **تأیید اتصال واقعی** | استاپ‌واتچ RIX-style: هسته بالا → شنونده باز → درخواست HTTP واقعی از تونل → IP خروجی. تا مرحلهٔ آخر «متصل» نمی‌گوییم. |
| 🔁 **جایگزینی خودکار** | اگر پروفایل انتخابی نتواند اتصال را ثابت کند، تا ۳ گزینهٔ رتبه‌بندی‌شده امتحان می‌شود و روش موفق به‌یاد می‌ماند. |
| 🧭 **اسپلیت تانل** | همهٔ اپ‌ها / فقط انتخابی‌ها / همه به‌جز انتخابی‌ها. خود Kuku همیشه مستثناست (بدون حلقهٔ مسیریابی). |
| 🛑 **Kill switch** | اگر تونل ناگهان بمیرد، رابط VPN بالا می‌ماند و ترافیک مسدود می‌شود — هیچ نشتی‌ای. |
| 📊 **آمار زنده** | دریافت/ارسال، مدت جلسه، IP خروجی و نمودار ۶۰ ثانیهٔ اخیر روی جریان جدا (بدون re-render کل صفحه). |
| 🧾 **گزارش رنگی** | لاگ زندهٔ هسته با کپی و پاک‌کردن. |
| 🌐 **دو حالت** | تونل کامل دستگاه (`VpnService`) یا فقط پروکسی SOCKS/HTTP محلی روی `127.0.0.1:2080`. |
| 🗣️ **فارسی + انگلیسی** | RTL کامل، انتخاب زبان در تنظیمات، پوستهٔ تاریک/روشن/سیستمی. |
| 🔍 **ورود کانفیگ** | لینک اشتراک (آپدیت دستی از لیست)، لینک تکی، QR اسکن، و Share-to-Kuku از مرورگر. |

## 🧩 پروتکل‌های پشتیبانی‌شده

`VLESS` (TLS / **Reality** / Vision / ws / grpc / httpupgrade) · `VMess` · `Trojan` · `Shadowsocks` · `Hysteria2` (با obfs) · `TUIC` v5 · `WireGuard` · `SSH`

لینک‌های قابل ورود: `vless://` `vmess://` `trojan://` `ss://` `hysteria2://` (و `hy2://`) `tuic://` `ssh://` `wireguard://` — و اشتراک‌های base64/متنی/JSON خود sing-box.

> **نقشهٔ راه:** AnyTLS و ثبت خودکار WARP از sing-box 1.12 به بعد در دسترس‌اند؛ نسخهٔ فعلی عمداً روی شاخهٔ پایدار 1.11 قفل شده تا اولین بیلد مطمئن سبز شود. راهنمای ارتقا در `docs/BUILD-TROUBLESHOOTING.md` آمده است.

## 🗺️ معماری

```
برنامه‌های اندروید
│
▼
VpnService / TUN  (اسپلیت تانل + مستثنا شدن خود اپ)
│
▼
هستهٔ sing-box  (libbox.aar ساخته‌شده با gomobile)
│   ├─ tun inbound (gvisor)
│   └─ mixed inbound 127.0.0.1:2080  ←  «تأیید اتصال واقعی» اینجا پروب می‌شود
│
▼
outbound انتخابی (VLESS/Reality …)
│
▼
اینترنت
```

نوار مراحل: **هسته → شنونده → تونل → خروج** — هر مرحله فقط با شاهد روشن می‌شود.

## 🛠️ ساخت از سورس

### روش رسمی — فقط با گیت‌هاب (بدون نصب هیچ ابزاری)

1. این مخزن را روی اکانت خودت fork/ایمپورت کن.
2. تب **Actions** را باز کن و ورک‌فلوی `android` را روی `main` اجرا کن.
3. بعد از سبزشدن دو job، در **Artifacts** فایل `kuku-apks` را دانلود کن:
   - `Kuku-<version>.apk` (release — اگر امضا تنظیم شده)
   - `Kuku-<version>-debug.apk` (برای تست سریع)
4. روی تگ `v1.0.0` push کنی، ورک‌فلو **GitHub Release** هم می‌سازد با `SHA256SUMS.txt` و attestation.

### کلید امضا (اختیاری ولی توصیه‌شده)

⚠️ **کلید را هرگز در چت، ایمیل یا خود مخزن نفرست.** فقط از مسیر Secrets:

```bash
# یک‌بار روی کامپیوتر خودت keystore بساز:
keytool -genkeypair -v -keystore release.keystore -alias kuku \
  -keyalg RSA -keysize 2048 -validity 10000

# به base64 تبدیل کن (فقط برای ورود به Secrets استفاده می‌شود):
base64 -w0 release.keystore > keystore.b64
```

سپس در گیت‌هاب: `Settings → Secrets and variables → Actions → New repository secret`:

| Secret | مقدار |
|---|---|
| `KUKU_KEYSTORE_B64` | محتوای فایل `keystore.b64` |
| `KUKU_KEYSTORE_PASSWORD` | رمز keystore |
| `KUKU_KEY_ALIAS` | `kuku` |
| `KUKU_KEY_PASSWORD` | رمز کلید |

تا وقتی این Secrets خالی باشند، بیلد release **بدون امضا** و debug با کلید دیباگ امضا می‌شود — و CI هشدار می‌دهد. کلید در گیت‌هاب به‌عنوان encrypted secret ذخیره می‌شود و ورک‌فلو یک گارد دارد که اگر روزی فایل امضا داخل مخزن کامیت شود، **بیلد را عمداً می‌شکند** (همان بهداشتی که ریکس بعد از حادثه‌اش اجرا کرد).

### ساخت لوکال (بدون CI)

```bash
scripts/build-libbox.sh      # libbox.aar را می‌سازد و در app/libs می‌گذارد (نیاز: go + NDK)
gradle :app:assembleDebug    # سپس APK
```

## 🧪 شناسنامهٔ فنی

| بخش | فناوری |
|---|---|
| رابط | Kotlin · Jetpack Compose · Material 3 |
| هسته | sing-box 1.11.x به‌صورت `libbox.aar` (gomobile bind) |
| تونل | `VpnService` + tun inbound (gvisor stack) |
| حداقل اندروید | 7.0 · API 24 |
| تنظیمات | DataStore + kotlinx.serialization |
| QR | zxing-android-embedded |
| مجوز | GPL-3.0-or-later |

مجوزهای اندروید فقط این‌هاست: `INTERNET`، `ACCESS_NETWORK_STATE`، `FOREGROUND_SERVICE(+SPECIAL_USE)`، `POST_NOTIFICATIONS`، `WAKE_LOCK`، `RECEIVE_BOOT_COMPLETED` (فعلاً بی‌عملکرد). بدون حساب کاربری، بدون SDK تحلیلی، بدون تبلیغ، بدون تله‌متری؛ cleartext و backup بسته است.

## 🧯 عیب‌یابی سریع

| نشانه | اولین بررسی |
|---|---|
| هیچ پروفایلی وصل نمی‌شود | لاگ تب «گزارش» دلیل هر کاندید را نشان می‌دهد؛ لینک/اشتراک تازه‌ای امتحان کن |

| Release بدون امضا | Secretهای `KUKU_*` را تنظیم کن |
| خطای کامپایل در `KukuVpnService` | `docs/BUILD-TROUBLESHOOTING.md` — با `javap` دو دقیقه‌ای حل می‌شود |
